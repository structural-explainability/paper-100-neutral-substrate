# Constraint Location in Ontology Design (Traditional)

## Design Objective

Create a shared ontology or consistent conceptual model for representing entities and relations within a domain.

## Constraint Location

Constraints operate on the ontology itself.

## Constraint Type

Restrictions on categories, relations, and logical structure.

## Typical Constraints

- taxonomic correctness
- logical consistency
- valid category relations
- identity and persistence rules

## Example Frameworks

- Basic Formal Ontology (BFO)
- DOLCE
- SUMO
- OntoClean

## Structural Pattern

world / ontology (shared conceptual model) / representations
