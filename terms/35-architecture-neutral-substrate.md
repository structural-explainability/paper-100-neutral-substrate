# Neutral Substrate Architecture

Structural layering of representation systems designed to support neutral substrates.

representation elements / representation system / representation substrate

| Property                  | Applies to                 |
|---------------------------|----------------------------|
| Extension                 | representation system      |
| Admissibility             | extensions of the system   |
| Invariance                | system structure           |
| Neutrality                | representation substrate   |
| Interpretive Independence | representation system      |

## Key Point for Neutral Substrates

- Extensions occur at the representation system layer.
- Structural constraints apply to the representation substrate.
