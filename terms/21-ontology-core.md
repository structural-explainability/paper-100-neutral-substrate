# Core Ontology Vocabulary

Entity.
Anything that exists or is posited to exist within an ontology.

Individual.
A particular entity not further divided into instances of the same type.

Category.
A class used to organize entities by shared ontological characteristics.

Relation.
A structure that holds between two or more entities.

Property.
A feature or characteristic attributable to an entity.

Identity.
The condition under which two references denote the same entity.

Persistence.
The principle governing how an entity remains the same across change or time.

Individuation.
The principle determining how entities are distinguished from one another.

Ontological Commitment.
A proposition that an ontology asserts as true within its representational system.
When an ontology asserts a proposition, the proposition becomes part of the
ontology's commitments.

Substrate Commitment.
A commitment asserted at the foundational layer of a representation system.
