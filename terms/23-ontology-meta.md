# Meta-Ontological Terms

Ontological Commitment.

Conceptual Scheme.
A system of categories used to structure interpretation of entities.

Level of Abstraction (LoA).
A perspective that selects which features of a system are relevant for analysis.

Representational Layer.
The structural level at which entities and relations are encoded.

Interpretive Layer.
The level at which meaning is assigned to representations.

Interpretation.

Representational Neutrality.

Semantic Underdetermination.
The condition in which multiple interpretations satisfy the same structural representation.

Framework Dependence.
