# Representation Vocabulary

Representation.
A structured description of entities, relations, or states within a system.

Substrate.
A structural layer that supports representations independently of particular interpretations.

Representation System.
A structured framework that defines how representations are formed, organized, and related within a system.

Representation Element.
A unit within a representation system used to describe entities, relations, or states.

Representation Structure.  
The arrangement of representation elements and relations within a representation system.

Representation Layer.
The level of a system at which entities, relations, and states are encoded independently of interpretation.
