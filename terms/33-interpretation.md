# Interpretation Vocabulary

Interpretive Framework.
A system of concepts and rules used to assign meaning to representations.

Interpretation.
The assignment of meaning to representations within a particular interpretive framework.

Interpretive Commitment.
An assumption embedded in an interpretation that presupposes a particular conceptual or ontological framework.

Interpretive Agreement.
A condition in which multiple participants assign compatible meanings to the same representations.

Interpretive Disagreement.
A condition in which different interpretive frameworks assign incompatible meanings to the same representations.
